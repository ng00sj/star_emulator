# Star Emulator v1.0
這是一個可以在真實星空資料模擬的星空中的移動的工具。我是做來自己玩的，預計做觸控滑動、搖桿控制前進等方式，並做類似找星星的遊戲，目標是透過這個工具更認識星空。
目前的資料來自Gaia，只有包含非亮星，預計之後補上亮星資料。

## 使用方式
* index.html：用滑鼠或觸控螢幕來在星空移動。
* index_walk.html：移動搖桿來在星空走動。
